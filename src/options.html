Organization repositories not working?

If your company uses SAML single sign-on, a valid token still gets rejected until you authorize it for that organization: github.com/settings/tokens → Configure SSO → Authorize. Test all names the organization when this is the problem.

Some organizations block classic tokens outright. In that case create a fine-grained token whose resource owner is the organization — an admin may need to approve it.

Triage is enough to file issues, but labels need push access — GitHub silently drops them otherwise, so Pin disables the picker and says so.
